Программа Lora Note AI создана в исследовательских целях, не для коммерции.

Lora Note AI - это приложение для голосового управления компьютером.
На данный момент функционал программы не отличается объёмомю
Вот перечень функций:
1) распознавание речи при помощи ии Vosk
2) выполнение простых команд на подобии открытия приложений (ключевое слово для всех команд Лора)
3) сканирование пк на наличие приложений
4) встроенный настраиваемый автозапуск
и т.д.
С полным перечнем функций можно ознакомиться скачав приложение, интерфейс не громоздкий и все кнопки говорят сами за себя.



Vosk не идеален и зачастую может ошибаться, именно поэтому я учу собственную нейронку которую можно будет дообучать на ошибках, но она появится не раньше релиза
